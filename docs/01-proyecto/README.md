# PROYECTO

Carpeta dedicada a explicar qué hace el proyecto, cuál es el plan y su gestión

El proyecto implementa un tablero Kanban compartido en tiempo real para la asignatura de Aplicaciones Distribuidas. La entrega actual comprende los módulos 1 y 2; los módulos 3 a 5 se desarrollan después.
