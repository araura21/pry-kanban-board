# Kanban Board - Memoria del proyecto

Kanban Board es un proyecto para la asignatura de Aplicaciones Distribuidas
que permitirá demostrar lo aprendido sobre un arquitectura cliente-servidor
usando sockets mediante un tablero interactivo basado en el método de gestión
evolutivo que se aplica a un flujo de trabajo del mismo nombre.

## Stack

- **Backend**: PHP y Laravel
- **Frontend actual**: vistas Blade, CSS y JavaScript en `kanban-board-app`; Vue o Angular quedan como una posible evolución futura.
- **BD**: PostgreSQL
